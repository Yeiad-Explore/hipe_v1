API COMMUNICATION FLOW
════════════════════════════════════════════════════════════════════════════════

User Input (SearchPage)
    ↓
SearchInput Component (validation)
    ↓
onClick handler (handleSearch)
    ↓
API Client (apiClient.search)
    ↓
Axios HTTP Request
    ↓
POST /api/search
    ↓
Backend Processing (10-30s)
    ↓
Response: SearchResult
    ↓
Update Component State
    ↓
Render: ResultCard + SourcesTable
    ↓
Add to History (useStore)

DATA FLOW
════════════════════════════════════════════════════════════════════════════════

1. User Types Query
   └─> SearchInput value updated (state)

2. User Presses Enter / Clicks Search
   └─> handleSearch(query) called

3. API Request
   └─> apiClient.search(query, platform, timeRange, threshold)
       └─> axios.post('/api/search', {...})
           └─> Backend processes
               └─> Returns SearchResult

4. Response Received
   └─> setResult(data)
   └─> addToHistory(query)

5. UI Updates
   └─> ResultCard displays answer
   └─> SourcesTable displays sources
   └─> Metrics show confidence/consensus
